# 시드 명단 CSV

`seed_mock_data.py`가 읽는 팀 공용 계정·가능시간 데이터입니다.
엑셀/스프레드시트로 열어 편집할 수 있고, **수정 후 PR → 팀원들이 `--reset` 재시드**하는 흐름을 따릅니다.

| 파일 | 내용 | 비고 |
|---|---|---|
| `departments.csv` | 부서 (id, 이름, 주간 한도, 정원) | id는 공고·직원이 참조하므로 임의 변경 금지. `weekly_hour_limit`(부서 운영 상한)은 **현재 비워 둡니다** — 아래 참조 |
| `staff.csv` | 직원 계정 | 공고 작성자(created_by)가 참조 |
| `students.csv` | 학생 계정 | `funding_type`: gyobi(교비)/gukga(국가) · `role`: applicant(지원 데모)/worker(정보서비스팀 근로, 공고 6 합격 자동 생성)/test-worker(정보서비스팀-test 근로, 공고 7)/aat-worker(아텍-test 근로, 공고 8)/grad-edu-worker(교육대학원 행정팀-test 근로, 공고 9) · `is_team_lead`: 학생팀장 표시 |
| `available_times.csv` | 학기별 주간 가능시간 | `term`: 학기 키, day_of_week: 월=1-일=7, 시간은 HH:MM, `preference`: 1=하/2=중/3=상 |
| `class_times.csv` | 학기별 수강 시간표 | 같은 형식이며 `preference`가 없다 — 수업은 선호가 아니라 근무 불가 제약 |
| `test_dept_availability.csv` | 정보서비스팀-test(부서 6)의 **날짜별** 수합 | 운영 스프레드시트를 그대로 옮긴 원본. `kind`: 가능/희망/수업 |
| `test_dept_daily_hours.csv` | 위 전사의 체크섬 | 시트의 '근무 가능 시간' 행. `tests/test_seed_test_department.py`가 대조한다 |

- `preference`는 숫자가 클수록 선호이며, 근무표 생성은 **3만 '근무 희망'으로 취급**해 우선 배정합니다 (SC-PREF-1). 3이 하나도 없으면 이 제약이 아무 일도 하지 않으니, 시드를 편집할 때 희망 시간대는 3으로 두세요.
- 가능시간은 **부서 개관 시간대를 빠짐없이 덮도록** 편집하세요. 정보서비스팀은 학기 평일 08:00-22:00 · 토 09:00-17:00이며(`scheduler/config/departments/library_info_service.json`), 가능자가 한 명도 없는 시간대는 생성 시 그대로 미충원으로 보고됩니다. 편집 후에는 개관 시간과 대조해 빈 칸이 없는지 확인하는 것이 좋습니다.
- `term`은 학사 캘린더(`scheduler/config/academic_calendar_2026.json`)의 학기 키입니다 — `2026-1`(봄)·`2026-summer`(여름방학)·`2026-2`(가을)·`2026-winter`(겨울방학). 시드는 **학기 중(`2026-2`)과 방학(`2026-summer`) 두 벌**을 넣습니다. 학생 화면·근무표 생성·부서 수합 조회가 모두 학기 단위라, 지금 학기에 데이터가 없으면 화면이 빈 채로 보입니다. 비워 두면 학기 도입 전 데이터(NULL)로 들어가 모든 학기에 함께 적용됩니다.
- 가능시간은 **부서 근무 블록 경계에 맞춰** 넣습니다 (`scheduler/config/departments/library_info_service.json`의 `work_slots`). 학생 화면(#89)이 블록 단위 체크박스라, 블록 중간에서 끊기는 구간은 체크되지 않은 것처럼 보입니다. 학기와 방학은 블록이 다릅니다 — 학기 평일 08:00-22:00·토 09:00-17:00, 방학 평일 09:00-20:00·토 09:00-17:00.
- 같은 학생의 `class_times.csv`와 `available_times.csv`는 **겹치면 안 됩니다**. 근무표 생성은 수업 시간표를 아직 직접 보지 않고(REQ-SCHED-015), 학생이 가능시간에서 수업을 빼고 냈다는 전제로 돕니다.
- 대타 후보 탐색(REQ-SUB-002)은 **구간 한 줄이 근무 시간을 통째로 덮을 때만** 후보로 잡습니다. 맞닿은 블록은 한 줄로 합쳐 두세요 (선호도가 다르면 줄이 갈라집니다).

## 대타 데모에는 근로 여력이 필요합니다 (#164)

시드는 다음 주부터 2주 확정 근무표를 **솔버로 생성**하고 그 위에 대타 요청 4건을 얹습니다.
그런데 부서 인력이 개관 수요보다 적으면 솔버가 capacity를 100% 소진해 **여력이 0**이 되고,
그러면 대타를 설 수 있는 사람이 없어 요청이 하나도 만들어지지 않습니다
(대타 승인은 대타 학생의 주간 상한을 검사합니다 — #159).

그래서 정보서비스팀 근로 학생을 **9명 → 11명**으로 늘렸습니다.

아래 **배정 시간 합계**는 "몇 명이 몇 시간 일했는지"를 모두 더한 값입니다 — 두 명이 같은
한 시간을 함께 근무하면 2시간으로 셉니다. 그래서 개관 시간(153시간)보다 클 수 있습니다.

| | 배정 시간 합계 |
| --- | --- |
| 개관 (2주) | 153시간 (슬롯 306개 × 30분) |
| 최소 인원(1명) 기준 필요 | 153시간 |
| 선호 인원(2명) 기준 최대 | 306시간 |
| 인력이 낼 수 있는 최대 | 국가 2×40 + 교비 9×28 = 332시간 (단, 교비는 HC-TIME-4로 부서 합 190시간) |

`available_times.csv`를 편집해 인원을 줄이거나 가능 시간을 좁히면 다시 여력이 사라질 수 있습니다.
시드는 그 경우 학생별 여력을 출력해 이유를 알려줍니다.

## 부서 운영 상한(`weekly_hour_limit`)은 지금 꺼져 있습니다

법정 상한(교비 주 14h · 국가 주 20h/40h)과 별개로, 부서가 자체 상한을 둘 수 있는 값입니다.
근무표 생성과 확정·수동 등록·draft 편집·대타 승인이 모두 `min(법정, 부서)`를 상한으로 씁니다.

**데모 범위에서는 노출하지 않기로 해서 값을 비워 두었습니다.** 비어 있으면 코드가 그냥
건너뛰므로 법정 상한만 적용됩니다 — 코드를 바꿀 필요가 없고, 다시 켜려면 이 CSV의
`weekly_hour_limit` 칸에 숫자를 넣고 재시드하면 됩니다.

- 화면에 표시되거나 설정하는 경로는 원래 없습니다 (프론트에 없고, 값을 바꾸는 API도 없음)
- 이미 값이 들어간 DB는 시드를 다시 돌리거나 `UPDATE department SET weekly_hour_limit = NULL` 로 끕니다
- 켤 때 주의: 부서 상한이 법정보다 낮으면 그만큼 배정 가능 시간이 줄어 미충원이 늘 수 있습니다.
  정보서비스팀은 15h였는데, 국가 근로가 학기 20h → 15h로 좁혀져 주간 배정 시간 합계가 138 → 128시간이 됐습니다 (#161)

## 정보서비스팀-test (부서 6)

근무표 생성을 **실측 수합 데이터**로 검증하기 위한 테스트 부서입니다. 운영 스프레드시트의 학생별 시트(2026-08-31 ~ 09-13, 2주)를 그대로 옮겼습니다.

- **이름·학번은 가명입니다.** 실명에서 한 글자만 바꿨고(팀 내부에서 누가 누군지 알아볼 수 있게), **학번은 전부 가짜**(`20261001`~`20261010`)입니다. 학생팀장 김찬우(`20261005`)만 팀에서 계정을 직접 쓰므로 이름을 그대로 뒀습니다.
- 반면 **전공·재원 구분·근무시작일·수합 시간표·수업 시간은 실제 값**입니다 — 근무표 생성을 실측 데이터로 검증하는 것이 이 부서의 목적이라, 배정에 영향을 주는 값은 그대로 둡니다.
- 이화정·유강훈 두 명은 운영 명단에 없어 전공·재원·근무시작일까지 임의값입니다.
- 시트는 날짜 단위인데 DB는 **학기별 주간 패턴 + 날짜 예외** 구조라, 시드가 이렇게 나눠 넣습니다:
  - `2026-2` 주간 패턴 ← **2주차**(09/07~09/12). '시간표 체크 완료'가 대부분 찍힌 주
  - `2026-summer` 주간 패턴 ← **08/31(월)**. 방학이라 학기 키가 다릅니다
  - **1주차 09/01~09/05** ← 날짜 예외. 종일 `UNAVAILABLE`로 그날 패턴을 지우고 그 날짜의 실제 구간을 다시 넣습니다
- 1주차 **수업 시간**은 주간 패턴으로 표현할 수 없어 넣지 않습니다. 근무표 생성은 수업 시간표를 직접 읽지 않고 "가능시간에 없으면 근무 불가"로 처리하므로(SCHEDULER_SPEC 2.1) 배정 결과는 같습니다 — 화면 표시용 값만 1주차에서 빠집니다.
- `test_dept_availability.csv`를 고쳤다면 `test_dept_daily_hours.csv`의 합계도 함께 맞춰야 합니다. 두 파일이 어긋나면 테스트가 막습니다.

- 공고·지원서처럼 여러 줄 텍스트·중첩 구조인 데이터는 CSV가 아니라 `seed_mock_data.py` 안에 그대로 둡니다.
- 모든 계정의 비밀번호는 스크립트가 일괄 설정합니다 (`stream1234`).
